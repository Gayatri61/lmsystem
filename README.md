# Learning Management System (LMS)

## 🇩🇪 Deutsch

### Projektbeschreibung
Dieses Projekt ist ein einfaches Learning Management System (LMS),
das mit Java 17, JavaFX und PostgreSQL entwickelt wurde.

### Funktionen
- Benutzerregistrierung und Login
- Kursübersicht und Kurssuche
- Kursanmeldung und Abmeldung
- Fortschrittsverfolgung
- Kursbewertungen
- JSON-Backup und Restore

### Voraussetzungen
- Java JDK 17
- Maven
- PostgreSQL

### Installation und Start

1. Repository herunterladen.
2. PostgreSQL-Datenbank `lms_db` erstellen.
3. Datenbankzugangsdaten in `DatabaseConnection` konfigurieren.
4. Anwendung starten:

   mvn clean javafx:run

## 🇬🇧 English

### Project Description
This project is a simple Learning Management System (LMS)
developed using Java 17, JavaFX and PostgreSQL.

### Features
- User registration and login
- Course overview and search
- Course enrollment and unenrollment
- Learning progress tracking
- Course ratings
- JSON backup and restore

### Requirements
- Java JDK 17
- Maven
- PostgreSQL

### Installation and Startup

1. Clone or download the repository.
2. Create the PostgreSQL database `lms_db`.
3. Configure the database credentials in `DatabaseConnection`.
4. Start the application:

   mvn clean javafx:run
